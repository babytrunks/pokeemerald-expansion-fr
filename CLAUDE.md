# Project Name: Pokemon Radical Red Rebooted, a reimagining of Fire Red in pokeemerald-expansion Engine

## Tech Stack
- **Language**: C, custom asm for pokeemerald use case, python for compilation purposes

## Project Structure

- `src/`: Main components for functionality of the game
- `include/`: Includes data defines for nearly everything in the project
